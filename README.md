### Key Takeaways

- Keep `CLAUDE.md` under **~200 lines** (~2,000 tokens)
- Use **`.claude/rules/`** for modular, topic-specific instructions
- Move documentation to **`docs/`**, not inline
- Use **`@path` imports** to reference external files
